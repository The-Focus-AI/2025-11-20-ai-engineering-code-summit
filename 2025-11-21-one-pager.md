# AI Engineering Code Summit - Day 2 One-Pager
## November 21, 2025

**The war on "slop" isn't won through clever engineering—it requires human thinking at the center, environments as universal abstraction, model capability over scaffolding, and open data to accelerate collective progress.**

## Key Insights

**DO NOT OUTSOURCE THE THINKING.** Dex Horthy surveyed 100,000 developers caught in rework cycles "fixing the slop from last week." His message: "AI can only amplify the thinking you've done." Jake Nations (Netflix) admitted shipping code he didn't understand. AI makes coding dangerously easy, but easy ≠ simple. When systems become complex, "everything touches everything else." Beyond 40% context window utilization, AI output quality collapses. Solution: intentional compaction—pre-research comprehensively, compress to focused markdown, phase-based workflows (research → plan → implement). Subagents exist for context isolation, not capability compensation.

**Environments are the universal abstraction.** Will Brown: "Environments are the webapps of research." Eno Reyes and Nik Pash independently discovered benchmarks, RL training, Skills, and artifacts are the same pattern: environment + starting state + verifier. Only difference is how rewards are used (measure vs. improve). Tea kettle verification: good verifiers test outcomes (is it whistling?), not processes (is burner on high?). Anthropic's Skills package institutional knowledge. Google DeepMind's artifacts are interactive verification spaces. This unifies training, evaluation, and deployment into single framework.

**RL democratizes specialization.** OpenAI's ARFT: 1,000 examples → 10-point improvements. Mako achieved 72% gains over frontier models with 100 PyTorch examples. Applied Compute's pipeline RL makes training fast, cheap, predictable. Meta's Code World Models learn from execution traces (memory, bash, CI builds). Aparna Dhinakaran's prompt tuning: +6%, +15%, +5% with 150 examples. Practical pattern: smart models for planning, fast specialized models for execution (Cursor's Composer, Amp's smart/rush).

**Capability beats scaffolding.** Nik Pash: "Agents aren't bottlenecked by clever tricks anymore. Model strength is the main thing." Terminus beats everything with minimal tool design—just terminal, grep, filesystem. "I'm tired of all the little hacks." Years of elaborate architectures = symptoms of compensating for model limitations. Even Amp's subagents exist for context management, not capability compensation. Age of clever tricks ending. Age of capability here.

**Data is the new bottleneck.** Pash's "truth nuke": production agents collecting goldmine data but keeping it locked, choking research. Every AI coding agent in production sits on quality training data. Almost none shared. OpenAI ARFT proves 1,000 high-quality examples transform models. Pash's Cline-bench: open-source, real-world agent coding benchmark from opt-in user data. Prime Intellect's environments hub provides infrastructure. Stack is ready. What's missing is courage to choose open science over proprietary moats.

## What To Do

- **Never outsource thinking** - Keep humans in charge of architecture. Phase-based workflows with checkpoints. When AI "agrees with everything," context is lost.

- **Master 40% context threshold** - Pre-research, compress to markdown, deploy subagents for isolation, compress aggressively above 40%.

- **Design verification-first** - Define outcome verifiers before code. Test results, not methods. Invest in eval engineering.

- **Explore specialization spectrum** - Prompt tuning (150 examples), ARFT (1,000 examples), pipeline RL (production-scale). Smart-for-planning, fast-for-execution.

- **Invest in capability, not scaffolding** - Focus on improving base models through better training data and evals.

- **Contribute to open data** - Opt-in trajectory collection, contribute anonymized data to benchmarks. Collective progress > proprietary moats.

---

**Bottom line:** Five interconnected principles form the architecture of quality: human thinking at center, environments as abstraction, specialized models through RL, capability over scaffolding, open data as infrastructure. Models only get better when labs train on something hard.
