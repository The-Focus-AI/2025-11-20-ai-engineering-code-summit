# AI Engineering Code Summit 2025-11-20 - One-Pager

**Trust is the new bottleneck—as economics shift, support teams, managers, and non-engineers all push code, transforming engineers into code reviewers who need deterministic validation at scale.**

## Key Insights

**The economics are changing who writes code.** When AI generates a developer's annual salary worth of tokens for $100/day, previously impossible projects become feasible and different people can contribute. Zapier support teams achieved 70% accuracy and moved into engineering roles. Tenex pays engineers $1M+ on output-based compensation. Travelopia replaces legacy apps in 4-6 weeks with half the team. Result: code review velocity is now the critical constraint.

**Code review is the new bottleneck.** 82% use AI assistants, but 76% don't trust the output (Qodo). The problem isn't buggier PRs—it's *volume* of PRs requiring review. McKinsey found 93% stuck in "pilot purgatory." The gap isn't AI capability—it's review capacity and trust infrastructure built on psychological safety (Google Project Aristotle: treat as systems problem, not people problem).

**From reactive to proactive agents.** Current tools force context-switching ("reminding the husband to do the dishes"). Google's Jules and Replit's autonomous agents shift to observation, timely action, and personalization—suggesting tasks with rationale, learning what you ignore. Autonomous testing breaks feedback bottlenecks and prevents "accumulation of whatevers."

**What's good for humans is good for AI.** Capital One's Max Kanat-Alexander: agents "did not attend your verbal meeting that has no transcript." The same investments that make human developers productive (better tooling, clear docs, robust testing, written context) are exactly what AI agents need. Stop building for agents, start fixing foundational problems.

**Clean code amplifies AI gains 4x, and the harness is where you win.** Stanford's 120,000-developer study: clean codebases see 35-40% productivity gains, messy ones see 0-10%. This "rich gets richer effect" threatens to bifurcate the industry. Meanwhile, OpenAI's principle: "Steerability = intelligence + habit"—the harness (context management, tool orchestration, prompts) is competitive advantage. Replit's fresh context prevents "context pollution." Models improve, but your architecture determines differentiation.

## What To Do

- **Build trust infrastructure through psychological safety** - Systems problem, not people problem. Establish feedback loops. Create deterministic validation processes.

- **Invest in code review velocity** - Autonomous testing, intelligent review tools, quality gates. "Don't accept PR without minimum testing." Review capacity determines if you capitalize on diverse contributors.

- **Rethink what's economically viable and who can build it** - 100x cost reduction means tackling previously shelved projects. Northwestern Mutual: use actual messy data, bring stakeholders into research, deliver incremental ROI. Escape pilot purgatory.

- **Invest in code cleanliness NOW** - Document context (agents didn't attend meetings), standardize environments, refactor for testability. Unlocks 4x productivity gains. Fight the entropy.

- **Build the harness, not model dependencies** - Focus on context management (memory + editing), tool orchestration, abstraction layers that survive model churn. Special sauce = architecture, not model choice.

- **Start with unglamorous, high-ROI use cases** - Bloomberg's uplift agents (tedious migrations), incident response agents (alert overload). Where don't developers want to work? What's now economically feasible?

---

**Bottom line:** AI isn't replacing software engineering fundamentals—it's exposing which organizations have them. Clean codebases: 35-40% gains. Messy codebases: 0-10%. Organizations winning aren't racing to adopt every model—they're methodically building foundations (clean code, clear processes, stakeholder trust) that allow AI to deliver measurable value.
