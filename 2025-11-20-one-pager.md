# AI Engineering Code Summit 2025-11-20 - One-Pager

**AI isn't replacing software engineering fundamentals—it's amplifying them. Clean code yields 35-40% productivity gains; messy code yields 0-10%. Organizations winning are fixing foundational problems that have plagued development for decades.**

## Key Insights

**Trust through infrastructure.** Capital One's Max Kanat-Alexander: "What's good for humans is good for AI." Better tooling, clearer documentation, robust testing benefit everyone. Proof: Zapier support team members achieved 70% accuracy with AI tools and moved into engineering roles, doubling velocity to 3-4 fixes/week. At Every (15 people, 7-figure revenue), managers commit code and new hires are productive day one.

**The harness is the new moat.** While models commoditize, OpenAI processes dozens of trillions of tokens/week through their "harness"—the abstraction layer encompassing prompts, context management, agent loops, and tool orchestration. 76% of developers distrust AI code because they distrust the *context* it has. Replit uses subagents with fresh context to prevent "context pollution." Anthropic combines Memory + Context Editing. Your strategic IP is the architecture, not the model.

**Clean code = 35-40% gains vs 0-10%.** Stanford's 120,000-engineer study reveals a "rich gets richer effect": environment cleanliness determines whether AI delivers massive productivity or nothing. Bloomberg's Lei Zhang warns: "2 engineers can create tech debt of 50 engineers" through vibe coding. On greenfield projects, AI tools deliver 35-40% gains. On brownfield codebases, gains collapse to 0-10%.

**ROI requires real data and trust-building.** Northwestern Mutual in Fortune 100 financial services: stop using synthetic data, bring business stakeholders into research, deliver incremental ROI. Only 7% of organizations believe they're at scale; 93% stuck in "pilot purgatory" (McKinsey). Bloomberg pivots to unglamorous high-ROI tasks: incident response, migrations—work developers hate but with clear value.

**Economics are breaking.** When AI generates a developer's annual salary in tokens for $100/day, time-based compensation becomes obsolete. Tenex pays engineers like salespeople—output-based, uncapped—with multiple on track for $1M+ annually. Gene Kim: when costs drop 100x, "annoying things become free."

## What To Do

- **Invest in code cleanliness before scaling AI** - Refactor for testability, deterministic validation, write down tribal knowledge. This is the 35-40% vs 0-10% difference.

- **Build your harness as strategic IP** - Context management, subagent architecture, memory systems. Models commoditize; your abstraction layer won't.

- **Start with unglamorous, high-ROI tasks** - Incident response, migrations, work developers hate with clear ROI.

- **Use real messy data from day one** - Bring stakeholders into research. Build trust incrementally, not big-bang.

- **Build autonomous testing** - Break the code review bottleneck. "More bugs because more PRs, not buggier PRs" (Qodo).

- **Rethink compensation** - If AI 10x's productivity, align incentives. Output-based models match the new reality.

---

**Bottom line:** AI rewards excellence and punishes mediocrity. The 35-40% gains are real—but only for organizations willing to fix their code quality, testing infrastructure, and documentation first. "What's good for humans is good for AI" is the north star.
