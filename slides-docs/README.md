## Key Themes

1. **Verification is Critical** - Multiple talks emphasized that AI agents need robust testing/verification infrastructure
2. **Multi-agent Architectures** - Companies moving toward specialized agents (ant colonies vs monolithic)
3. **Productivity Gap Widening** - Stanford research shows 4x increase in gap between AI adopters and non-adopters
4. **Code Quality Matters** - Clean codebases amplify AI effectiveness; technical debt degrades it
5. **Human-in-the-Loop** - Most successful approaches maintain human oversight and review cycles
6. **Exponential Capability Growth** - METR research shows steady exponential improvement in task horizon
7. **Operating Model Changes** - McKinsey argues different work types need different human-agent collaboration models
