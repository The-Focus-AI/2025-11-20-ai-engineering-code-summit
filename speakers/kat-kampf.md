## Current Work: Gemini Era Products

### Google AI Studio (ai.studio/build)

A free-to-use platform for building AI applications with integrated Gemini capabilities:

- **Accessible to Everyone:** Democratizing AI development for developers of all skill levels
- **Google Search Grounding:** Integrated search capabilities allow applications to pull real-world, up-to-date information
- **Agentic Tool Calling:** Native support for building autonomous systems that can call multiple tools
- **Interactive Sharing:** Build once, share applications seamlessly across teams and users
- **No Backend Complexity:** Abstracts away infrastructure concerns, letting developers focus on intent

### Gemini 3 Pro Features

The latest generation Gemini model brings significant improvements:

- **UI and Sensibility:** Improved understanding of visual design and user interface principles
- **Agentic Capabilities:** Enhanced tool calling and multi-step reasoning for complex tasks
- **Multimodal Understanding:** Can process and work with images, code, and text together
- **Intelligence at Scale:** Enables building ambitious applications that require deep reasoning

### Backend and Runtime Support

Google is abstracting away the complexity of backend infrastructure:

- **Full Backend Support:** Developers don't need to manage servers, databases, or deployment
- **Runtime Execution:** Built-in systems for executing code safely and efficiently
- **Simplified Deployment:** Focus on application logic, not infrastructure management

## Key Vision: "First Generation Where Anyone Can Build Software"

Kat and Ammaar's core message is that AI has reached a maturity level where the barrier to entry for software development is fundamentally removed. Key implications:

### Democratization

- Tools are free and accessible
- No special technical infrastructure required
- Non-engineers can build functional applications
- Lowered friction between idea and execution

### Agentic Design Philosophy

- Applications built with tool-calling at their core
- Systems that can make decisions and take actions independently
- Integration of search, computation, and user interfaces

### Design as First-Class Concern

- Moving beyond code-centric development
- Visual design treated as a primary specification
- UI/UX principles directly influence model behavior
