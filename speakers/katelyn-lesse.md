## Champion of Autonomous AI Agents

Katelyn Lesse has become a leading voice in building "unhobbled" autonomous agents, advocating for giving Claude computer access, external system connections, and code execution capabilities. Her work focuses on enabling agents to work effectively for hours on complex tasks without hitting context limitations.

## Philosophy on Agent Development

Katelyn's approach centers on balancing capability expansion with constraint management:

**Core Agentic Stack:**
1. Tool Integration & Skills Framework - Structured capabilities for agents
2. MCP - Composable connections to external systems
3. Memory System - Intelligent context retrieval
4. Context Editing - Token management and window optimization
5. Code Execution - Native tool capabilities

**Best Practices:**
- Memory + Context Editing Combined = optimal context management
- "Giving Claude a Computer" - foundational metaphor for autonomous work
- Long-running Agents - techniques enable Claude to work for hours on complex tasks
