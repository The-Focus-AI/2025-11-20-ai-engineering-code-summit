## About Sourcegraph
Sourcegraph is the code intelligence platform that lets developers and agents search, understand, and automate changes across codebases. The company develops code search and intelligence tools that semantically index and analyze large codebases. With products including Code Search, Amp (agentic coding agent), and Cody (AI assistant), Sourcegraph empowers enterprises including Uber, Dropbox, and Lyft to manage complex codebases.

## Speaker Background
Steve Yegge is a legendary figure in software engineering with over 40 years in the tech industry, including 19 years combined at Google and Amazon. At Google (2005-2018), he built Grok, a code intelligence platform that lives on today as Google Kythe. He joined Sourcegraph in October 2022 as Head of Engineering after coming out of retirement, drawn by the company's development of SCIP (Source Code Intelligence Protocol) - which he describes as "the return of Grok." He is co-authoring "Vibe Coding: Building Production-Grade Software With GenAI" with Gene Kim and Dario Amodei, and is the architect behind Amp, Sourcegraph's next-generation agentic coding tool.

## Research Notes
Steve Yegge is at the forefront of AI-driven developer tools and coding agents. His vision of "vibe coding" challenges traditional IDE paradigms, arguing that AI agents should handle the grunt work while developers focus on high-level goals. During the summit session, he made bold claims such as "If you are still using an IDE by Jan 1st you are a bad engineer," reflecting his belief that agent-driven development is the inevitable future.

His open-source Beads project (released October 2025) directly addresses a critical problem in agent development: memory and context persistence. By providing agents with a git-backed issue tracker and dependency system, Beads enables agents to maintain state across sessions and execute complex multi-step plans.

Yegge's career trajectory shows consistent focus on code intelligence and developer tooling. His Google Grok project, while not directly open-sourced, influenced modern code analysis tools. His return to this domain at Sourcegraph positions him to potentially reshape how developers interact with their codebases in the AI era.

He actively promotes the CHOP (Chat-Oriented Programming) paradigm and frequently discusses the cognitive overhead of current coding tools, using the metaphor of "power tools" to describe AI-assisted coding - powerful but dangerous without proper training and oversight.
